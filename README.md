# CampusFind – AI-Powered College Lost & Found System

CampusFind is a senior/student-friendly campus lost-and-found application built with Flutter and FastAPI.

## Stack
- Flutter / Dart
- FastAPI / Python
- PostgreSQL
- SQLAlchemy
- JWT authentication
- Explainable AI matching
- Docker Compose

## Demo
Use `QUICKSTART.md` for the exact run commands.

The AI matcher compares category, color, brand, description, location and date signals and produces a similarity score. Scores are suggestions and are not proof of ownership.
